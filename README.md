# Shahroz Ahmed — Senior IT & AI Solutions Architect Portfolio

A high-performance, minimalist editorial portfolio website for **Shahroz Ahmed** (Senior IT & AI Solutions Architect), inspired by Swiss-grid typography and featuring an authentic Framer celestial aurora 16:9 scroll parallax engine.

---

## 🌟 Highlights & Features

- **Framer 16:9 Celestial Aurora Parallax Engine**: Full-screen edge-to-edge canvas with high-resolution video background, soft grey arch, white-teal radiant glow, and mathematical elliptical curve tracking during scroll.
- **Minimalist Editorial Swiss-Grid Design**: Clean typography combining `Syne` (display headers), `Cormorant Garamond` (editorial serif accents), `Plus Jakarta Sans` (body), and `JetBrains Mono` (technical badges & metrics) on a warm `#FCFCFB` canvas with frosted glassmorphism pills and cards.
- **Interactive Scope & Cost Estimator**: Live dynamic quote calculator allowing prospective clients to customize architecture paradigms (RAG, Agents, Sovereign Platforms), delivery velocity, and add-ons with instant compilation to pre-filled WhatsApp and Email messages.
- **Interactive Aria AI Advisor Drawer**: Slide-out technical advisor drawer preloaded with responses on architecture standards, sub-0.05 RAG hallucination guardrails, and rapid MVP turnarounds.
- **Services & Capabilities Catalog**: Filterable technical offerings (Enterprise RAG, Autonomous Agents, Custom Fine-Tuning, Cloud Infrastructure) alongside 6 value bento cards.
- **Zero Heavy Build Dependencies**: Clean semantic HTML5, modern vanilla JavaScript, and Tailwind CSS.

## 🚀 Local Development

To run the site locally:

```bash
# Using Python
python3 -m http.server 8080

# Or using npx
npx -y serve .
```

Then open `http://localhost:8080` in your browser.
